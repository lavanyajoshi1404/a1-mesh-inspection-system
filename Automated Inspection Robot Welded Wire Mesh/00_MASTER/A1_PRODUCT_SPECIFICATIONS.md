## Important Engineering Note

These specifications are reference parameters for the software
architecture.

They must not automatically be interpreted as inspection tolerances.

No PASS/FAIL tolerance should be invented.

If an exact product configuration or tolerance has not been verified,
the system should report the measured value without creating an
unsupported acceptance decision.
