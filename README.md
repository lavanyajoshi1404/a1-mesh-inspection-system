# A1 Mesh Inspection

## Automated Quality Inspection Robot for Welded Wire Mesh Production

A camera-based visual inspection system developed by **Team A1 Titans** for automated visual inspection of welded wire mesh.

The system combines a conveyor-based inspection setup with controlled imaging, computer vision and digital inspection records to analyse repeated mesh geometry and identify regions requiring review.

## Project Overview

Welded wire mesh contains repeated geometric structures that need to remain consistent during production.

Traditional visual inspection can involve repetitive manual checking of:

- Mesh spacing
- Wire alignment
- Weld/intersection locations
- Visible surface irregularities
- Inspection traceability

The objective of this project is to create an **automated visual inspection layer** that captures the mesh under controlled imaging conditions, analyses its geometry and generates reviewable digital inspection evidence.

### Core workflow

```text
MESH

CONVEYOR
  ↓

  ↓
IMAGE CAPTURE
  ↓
COMPUTER VISION
  ↓

  ↓

  ↓

  ↓

  ↓
  DIGITAL RECORD
```
